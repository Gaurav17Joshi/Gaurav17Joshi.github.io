Work

  • 2025.09 - Present

    San Diego, CA, USA

    Graduate Researcher
    UC San Diego – Center for Visual Computing
    Advisors: Manmohan Chandraker (Prof., UCSD), Kunal Gupta (PhD, UCSD)
    • BlendCUA: Self-Evolving Computer-Use Harness for Blender (first author). Built a computer-use agent that turns natural-language briefs and reference images into Blender assets across modelling, materials, physics simulation and animation, and that improves its own harness (tools, skills, plan checks) from experience with the model kept frozen.
    • Proposed learning from the defects in the agent's finished work instead of from successful trajectories, and implemented the loop end to end: an independent checker agent, a curator agent that attributes each defect to the plan, review, execution or reference views, and a rebuild gate that keeps a new skill or tool only if it fixes the defect.
    • Outperformed existing harnesses such as Claude Code and Codex on held-out tasks, with most learned tools and skills reused on later tasks. Under review at ICLR 2027.
    • Procedural Material Generation from Expert Workflows (ECCV 2026). Researched agentic LLM systems that learn from expert video demonstrations and reason over expert workflows to produce executable outputs, applied to procedural materials in Blender.
    • Knowledge extraction: built automated pipelines that turn Blender tutorial videos into structured procedural knowledge using video understanding and LLM-based reasoning.
    • Generation: helped develop retrieval-time reasoning agents that use this knowledge to plan expert-style material creation processes and compile them into executable Blender node graphs.
    • Supported expert and large-scale user studies showing improved workflow quality over graph-only generation baselines; paper accepted at ECCV 2026.
